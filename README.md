# WhatToEat 🍽️

WhatToEat is a food recommendation web application that helps users decide what to eat based on mood, cravings, cuisine preferences, or meal type.

## Features

- 🍕 Food recommendations based on user preferences
- 🔍 Search foods by cuisine or category
- ❤️ Save favorite dishes
- 👤 User authentication (Login / Register)
- 📱 Responsive modern UI
- ⚡ Fast and easy navigation

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB
